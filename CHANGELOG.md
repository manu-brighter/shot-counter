# Changelog

## [1.2.0](https://github.com/manu-brighter/shot-counter/compare/v1.1.1...v1.2.0) — 2026-11-05

- Update frontend, backend and desktop dependencies, including indirect security fixes.
- Upgrade to Vue 3.5, Vuetify 4.3, Vite 8.3, Vue Router 5 and Electron 45.
- Upgrade SQLite bindings to better-sqlite3 13 with bundled N-API binaries.
- Use built-in Vue Router file routing and wire the default layout directly, removing obsolete build plugins.
- Require Node.js 22.18+ or 24.11+ and npm 11.19+; use Node.js 24 LTS for development and releases.
- Update GitHub Actions and keep stable Windows/Linux download filenames.
- Disable repository Dependabot alerts and automatic security updates; maintenance is on demand.
